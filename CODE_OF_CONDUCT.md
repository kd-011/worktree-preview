# Code of conduct

This project is for fixing and improving a small tool. Be civil, be specific, and assume the other person is trying to help.

## What we expect

- Criticise the code or the idea, not the person.
- Keep issues and reviews on topic and give enough detail to act on.
- Accept that a maintainer may decline a change, and say so plainly if you disagree.

## What is not acceptable

- Harassment, insults, slurs or personal attacks.
- Publishing someone else's private information.
- Spam, or repeated pushing after a decision has been made.

## Enforcement

Maintainers may edit or remove comments, close or lock threads, and block people who break these rules. To report a problem privately, use "Report a vulnerability" on the Security tab and say it is a conduct report. That is the only private channel this project has. Reports are read by the maintainer and kept confidential.

This applies in the repository's issues, pull requests and discussions.
